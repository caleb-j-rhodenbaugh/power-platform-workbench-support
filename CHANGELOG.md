To configure a deployment from Workbench:

1. Select the Dataverse/Azure accounts and Azure resources in **Accounts**. The Azure selection and Dataverse **Target** remain separate.
2. Right-click a prepared `*.appsettings.json` or `*-appsettings.json` string-object file and choose **Diff**. Select Function App or Standard Logic App and supply any target details not already selected in **Accounts**, review each changed setting, then **Deploy** only the checked settings. Other settings are preserved from a fresh read. Applying app settings can restart the app. Azure replaces the complete settings collection without documented conditional-update support, so avoid simultaneous configuration edits.
3. Continue using file/manifest **Diff → Deploy** for the complete Function App, individual Standard Logic App workflow, solution component, and website files. App-setting files have their own configuration review and are not compiled Function payloads.
4. In **Azure Diagnostics**, choose the Logic App callback workflow. Select its request trigger and enter the app or existing gateway hostname. **Copy Callback URL** copies the existing signed URL to the clipboard, preserving its path and query. It does not regenerate keys or configure a gateway.
5. In **Review Target Configuration**, use **Edit Current Value** to set an environment variable's Current Value while leaving its Default Value unchanged. The reviewed option to remove the value from the selected solution removes membership only; it retains the working value. For website work, set **Accounts → Dataverse → Power Pages solution** for the selected Target. Use **Review Solution Membership**, choose the intended Power Apps or Power Pages solution, then **Add existing components** to review and add the exact environment-variable definitions and enhanced Power Pages components. Power Pages solutions use the same native Dataverse solution catalog; the saved default does not classify solutions or change the header selection.
6. In **Power Pages Diagnostics → Target Website**, select the website, then **Open Website** or **Restart Website**. Restart requires confirmation and briefly interrupts the selected site. It is not design studio Sync. Verify the deployed behavior in the live site after restart.
