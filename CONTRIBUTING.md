# Contributing to Power Platform Workbench

This repository accepts public bug reports, feature requests and improvements to the support documentation. The extension implementation is maintained privately.

## Before opening an issue

- Search existing issues and add a useful, sanitized reproduction to an existing report when appropriate.
- Record the extension version, VS Code version and relevant installed tool versions.
- Describe the exact Workbench tool or context-menu action and whether the operation may have changed its Target.
- Reproduce with synthetic data and generic names when possible. Do not copy a customer's workspace into an attachment.

Use the [bug or feature forms](https://github.com/caleb-j-rhodenbaugh/power-platform-workbench-support/issues/new/choose). Keep one distinct problem or proposal per issue so that status remains clear.

## Protect private information

Everything posted here is public. Redact identities, organization names, environment/resource URLs, local paths, identifiers and business data. Do not submit authentication material, signed URLs, exported solutions, deployment packages or production records. A public issue is not an appropriate way to transfer a private project for troubleshooting.

Report suspected security vulnerabilities according to [SECURITY.md](SECURITY.md). Do not disclose vulnerability details through an ordinary issue.

## Documentation changes

Small pull requests that improve this repository's generic instructions or issue templates are welcome. Preserve accurate capability boundaries, avoid promising unsupported platforms, and use only fictional examples. Do not submit extension source, generated binaries or client-specific instructions here.

By contributing documentation, you agree that your contribution can be distributed under this repository's MIT license. You must have the right to share what you submit.

## Triage

Maintainers may request a smaller reproduction, clarify scope, link related issues or close duplicates. Reports are handled on a best-effort basis. A milestone, label or project-board placement is not a commitment to a delivery date.
