# Workbench command access inventory

Generated by `Update-CatalogDocumentation.ps1` from the tested canonical registry and actual command contributions. Every contributed command has an existing human access route and MCP owner/classification. Context actions keep their file, row or retained-review scope; they are not additional pane launchers. Component Recycle Bin is in Deploy. Preview UI Locally is in Develop. Settings owns Agent Access and workspace controls. Hidden internal commands and conditionally available Command Palette commands are identified explicitly.

## Data

| Tool | Purpose | Key |
| --- | --- | --- |
| Query Data | Query one table from the selected solution in Target and its related records. Select columns and filters, or edit the same query in the URL, JSON or XML editor. Download results as CSV, Excel or JSON. | `queryData` |
| Import Data | Import CSV, Excel or JSON into the Target: map columns, preview changes, then confirm the import. Reconcile outcomes from the import results. | `modifyData` |
| Restore Deleted Records | Find eligible deleted Target records and confirm their restoration from the recycle bin. | `restoreDeletedRecords` |
| Profile Data | Measure nulls, distinct values and duplicate groups in an explicitly loaded record sample. | `dataProfile` |
| Inspect Record Audit History | Inspect available audit changes and review restoring explicitly selected complete scalar values. | `dataAudit` |
| Edit Record Relationships | Review adding or removing exact many-to-many links without deleting related records. | `dataAssociations` |
| Transfer File and Image Columns | Download files or review uploading a local file to a selected Dataverse File or Image column. | `dataFiles` |
